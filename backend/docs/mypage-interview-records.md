# 마이페이지 면접 점수·기록

마이페이지 상단에서 완료된 면접의 최초 점수와 가장 최근 점수를 비교한다. 다섯 가지 역량(자신감, 끈기/열정, 전문성, 논리력, 전달력)을 100점 척도의 오각형 그래프로 표시하며 최초는 주황색 점선, 최근은 파란색 실선이다. 점수 표, 종합 점수 변화와 완료 횟수도 함께 표시한다.

최초·최근은 `INTERVIEW_DATE` 순서로 결정하고 동일 시각이면 `HISTORY_NUM`으로 구분한다. 기록이 하나라면 두 그래프는 동일한 점수를 표시하며 안내 문구를 보여준다. 기록이 없으면 첫 면접 시작 링크를 보여준다.

그래프는 왼쪽, 면접 기록과 문서 관리는 오른쪽에 세로로 배치하며 양쪽 열의 너비와 전체 높이를 맞춘다. 좁은 화면에서는 아래로 배치하고 개인정보 수정 영역은 그 아래에 표시한다. 면접 기록과 문서 목록은 카드 내부에서 스크롤되며 데이터가 많아도 카드 높이가 늘어나지 않는다. 기록 목록은 전체 기록을 최근순으로 표시한다. 기록을 선택하면 상세 대화상자에서 역량 점수, 평가 피드백 4종, 질문·답변 5쌍을 조회한다. 키보드 Escape 또는 닫기 버튼으로 닫을 수 있다. 목록과 상세 조회 실패 시 재시도를 제공한다.

## API

- `GET /api/interview/results`: 로그인한 회원의 완료된 면접 결과 목록. 기존 결과 DAO·쿼리를 사용한다.
- `GET /api/interview/{historyNum}/record`: `{ history, result }`를 반환한다. 기존 질문·답변과 평가 조회 쿼리 모두 인증된 회원 번호로 제한한다.
- 미인증 요청은 401, 존재하지 않거나 다른 회원의 기록 또는 평가가 없는 기록은 404를 반환한다.

기존 `T_INTERVIEW_HISTORY`, `T_INTERVIEW_RESULT`를 사용하며 추가 DB 변경은 없다. 기존 데이터에 저장되지 않은 면접 방식·난이도·지원 직무는 추정하여 표시하지 않는다.

## 검증

- 프런트엔드 빌드 및 신규 컴포넌트·API 코드 검사.
- 점수 정렬, 같은 날짜의 순서, 빈 기록·단일 기록, 오각형 좌표와 점수 형식 테스트.
- 백엔드 전체 소스 Java 17 대상 컴파일 및 기존 면접 테스트와 신규 기록 API 테스트. 로컬 JDK 26과 설치된 의존성을 사용했으며 Maven 패키징은 실행하지 않았다.
- 브라우저에서는 테스트 데이터로 그래프, 기록·문서 목록 내부 스크롤과 반응형 배치, 상세 질문·답변, 단일 기록과 빈 기록, 목록·상세 조회 실패 후 재시도를 확인했다. 실제 Oracle 연결·운영 데이터 검증은 수행하지 않았다.

면접 이어하기와 하루 이용 제한은 이 작업에 포함하지 않는다.
